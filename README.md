# Prise en main de Bootstrap.
Voyage en row trouble: Projet Simplon pour construire une interface utilisateur responsive à l'aide du framework CSS Bootstrap.

## Contexte du projet
Le restaurant Oceanside souhaite mettre en ligne une nouvelle version de son site. 
Il fait appel à vous pour la créer à partir des maquettes fournies par son graphiste à vous de les reproduire à l’identique!

## Critères de performance
Le site est responsive et correspond à la maquette
